## Executive recommendation

Do **not** replace the portfolio or invent a ninth generic consumer app. The current repository is already unusually broad for an early-career portfolio: eight named projects, an interactive systems page, graphic design collection, several working prototypes and substantial AFTERFORM and INTERVAL print/editorial systems. The most urgent changes are **selection, differentiated workflow evidence, honest process documentation and proof of real-world work**.

This intervention adds **PROOF**, a self-directed creative-operations concept demonstrating explicit version/approval states and campaign design, and changes the initial homepage view from eight equally promoted projects to six curated projects. The other existing projects remain accessible. PROOF is a complementary skill specimen, **not** a substitute for actual client or user validation.

## Role-specific hiring evaluation

**Graphic / Visual Design manager:** AFTERFORM and INTERVAL make brand and art direction credible. PROOF adds a different, more utilitarian typographic system and editable SVG masters. Main concern remains the distinction between conceptual print and real, specified, delivered artwork. For this reviewer, lead with AFTERFORM → INTERVAL → PROOF. Provide flattened/exported vector masters where appropriate and a print-production checklist; avoid claiming printer-ready files without preflight.

**UI / Web Design manager:** Existing sites demonstrate HTML/CSS/JS execution rather than static mockups. PROOF adds form errors, history, approval gates, input state and release logic. Lead with PROOF → Áurea → Holland → ImHere. Main concern remains cross-browser and accessibility verification; capture tested devices, screenshots and keyboard path evidence before applications.

**UX / Junior Product manager:** ImHere and Holland provide clear problem narratives and interaction tasks, while PROOF demonstrates state modeling. Main concern: direct research, usability evidence, real user feedback and collaboration. Lead with ImHere → PROOF → Holland; add clearly sourced process evidence without invented personas, quantitative claims or before/after results.

## Production and prototype boundaries

PROOF is a demonstration of information hierarchy, graphic art direction and local UI logic. It is **not** a multi-user approval service, file repository, PDF converter or operational print approval. Poster SVGs use device fonts and have no print bleed, embedded profiles, color managed exports or production preflight. The "release brief" is a browser print layout of sample state, not vendor authorization.

No client interviews, job placement improvements, production metrics, accessibility certification or revenue outcomes are claimed.
