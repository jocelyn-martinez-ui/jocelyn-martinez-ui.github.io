# PULP marketing emails

Three art-directed responsive, table-based HTML email concepts with inline CSS, hidden preheaders, Outlook ghost-table scaffolding, live text and text-only alternatives. They are local browser demonstrations. Cross-client rendering (Gmail, Outlook, Apple Mail, dark mode) is untested. CTA links use example.com and are not usable storefront links. Do not send without an authorized sender, compliant mailing details, working unsubscribe/preference management and confirmed audience consent.
