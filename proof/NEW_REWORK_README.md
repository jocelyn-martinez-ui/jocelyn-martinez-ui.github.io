# PROOF — Error to Edition (2026 review edition)

**Open `index.html`** in a modern browser. All visual assets are local; no server or network access is required. Main site is `index.html`, responsive styles `style.css`, interactions `app.js`, social photographs and export designs under `assets/`, and emails in `emails/`.

Built with original AI-generated photographic concept assets and programmatic typography. The implementation includes two email HTML templates, seven social compositions, a 12-page reading publication, one print advertising PDF and an interactive review demonstration.

This is intentionally a **new, coherent one-brand concept** rather than a minor restyling of the PULP/FIELD/TERRA trio.

To regenerate source artwork from the original imagery, run `python src/build_assets.py`, `python src/build_print.py` and `python src/build_emails.py`. The two original generated input PNGs are in `src/` in this download. The scripts use ReportLab, Pillow and locally installed typefaces; fonts are **not redistributed**.

## Technical honesty

- Photo-derived visuals are fictional concept art; not real production documentation.
- PDF reading pages are not commercial impositions or printer-approved PDFs.
- Emails are browser previews and require live sending setup, client testing and compliance review.
- The test site should be inspected before being merged into a live portfolio.
