# PROOF / Marketing email design system

Four **independently authored** responsive table-based marketing concepts with live HTML headings/copy, preheaders, image alt text, explicit HTTPS-hosted image URLs, Outlook max-width scaffold and text-only fallbacks.

| Email | Purpose | Distinct composition |
|---|---|---|
| 01-edition-launch | EDITION 01 / THE PUBLICATION | Photography opener + orange announcement block |
| 02-editorial-discovery | INSIDE THE ISSUE / FOUR CHAPTERS | Editorial text first + image chapter |
| 03-process-and-revisions | THE PROCESS / VISIBLE DECISIONS | Two-image revision comparison |
| 04-across-formats | THE SYSTEM / FORMAT STUDIO | Minimal content essay + horizontal signal bar |

**Shared reusable modules:** wordmark/header, title block, live paragraph, responsive photographic image, CTA table, 3-row education module, legal/provenance demonstration footer.

**Design tokens:** Ink `#181917`, paper `#f2efe8`, signal orange `#ff542d`, acid `#dbfa36`. Display font: Arial/Helvetica; reading: Georgia; details: Courier New.

**Actual production work needed:** mobile/desktop inbox testing in Gmail, Outlook, Apple Mail (not performed here); dark mode/inverted text, unsubscribe and sender validation, permissioned list, recipient opt-out, UTM/tracking decisions, image-host uptime and deliverability verification. Marketing links point only to existing fictional portfolio pages.

All image URLs refer to first-party artwork in the user's own GitHub Pages site. Do not send as a campaign without implementing a compliant sender footer and working unsubscribe links.
