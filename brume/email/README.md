# Three BRUME HTML email templates

- 01 introduction, 02 color/material study, 03 detail and follow-up.
- HTML is table-first, 600px with mobile CSS and Outlook conditional width scaffolding; plain-text alternatives present.
- Image files remain linked as relative local assets for portfolio preview. Before any real send, host them at accessible HTTPS URLs and re-test in Outlook, Gmail, Apple Mail, dark mode and images-off clients.
- CTA `https://example.com/brume` is nonfunctional by design; there is no sender identity, subscription data, legally required address or working unsubscribe infrastructure.
- The emails have not been sent and no clicks, conversions or testing results are claimed.
