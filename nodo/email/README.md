# NODO / Three-email lifecycle campaign

This directory contains three **standalone table-based HTML emails** with inline CSS, fluid 600px containers, conditional Outlook ghost tables, responsive mobile adjustments, preheaders, semantic headings, and text-only alternatives. Source was created for a self-directed marketing portfolio case study, not delivered as a live campaign.

| Step | Subject | Purpose |
| --- | --- | --- |
| 01-launch | Meet NODO: a little less desk noise | NODO / COLLECTION 01 |
| 02-the-system | Clip, wrap, guide: choose your desk reset | A NOTE FROM THE NODO STUDIO |
| 03-the-reset | One small desk reset, when you need it | NODO / A WORKING NOTE |

- CTA destination `https://example.com/nodo` is intentionally a non-operational sample.
- Footer includes an explicit demo notice. No sender domain, delivery infrastructure, live unsubscribe URL or list management is invented.
- Font fallback: Arial, Helvetica, Georgia. All vital content is live HTML text rather than image-only content.
- Browser rendering has not been verified against Gmail, Apple Mail, or Microsoft Outlook. Before any real mailing: Litmus/Email on Acid checks, dark-mode review, links/UTM, sender identity, unsub, spam/data compliance, and authorized opt-in audience checks.
- Copy is original speculative campaign material. No click, conversion, audience or sales outcomes are claimed.
