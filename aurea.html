01 / THE BRIEF

A language for scent.
A structure for choice.

Perfume vocabulary can be inviting and opaque at the same time. A database must help someone move between a note they recognize, a structured fragrance profile and the uncertainty of personal wear.

Who it is for

Curious fragrance beginners looking for a starting point, and enthusiasts comparing notes or keeping track of perfumes they want to sample.

What it should change

Make perfume information browsable and comparable without pretending that descriptive notes predict how a fragrance will wear on an individual.

Evidence, contribution & constraints

Self-directed concept informed by a heuristic review of the existing catalogue flow. The three fragrance records are original illustrative profiles. No interviews, brand-supplied data or wear-performance study are claimed.

Three sample records; client-side filtering, comparison and a journal for this visit. No live commercial catalogue, ingredient safety information, brand affiliation, purchase flow or longevity predictions.

01

More than one entry point

Search, fragrance family and individual notes support different levels of vocabulary.

The alternative & the tradeoff

A single recommendation quiz is welcoming but limits expert browsing and makes the result harder to inspect.

The optional finder supports discovery while the database remains directly accessible.

02

Keep useful intent

Active search, family and note filters can be removed separately after an empty result.

The alternative & the tradeoff

Resetting everything is simple to implement but forces the user to reconstruct a partly useful query.

The interface exposes filter state so recovery remains predictable.

03

Comparison is a decision space

Selecting a third fragrance asks which current selection to replace. Profile rows align family, opening, heart, base and character.

The alternative & the tradeoff

Unlimited comparison increases apparent power but becomes difficult to read on smaller screens.

Two profiles preserve legibility; replacing one supports exploration without starting over.

Beyond the ideal path

Interaction states and recovery
No resultsKeep the selected filters visible and removable one at a time.
One selectedAsk for one more perfume before showing a comparison.
Two selectedExpose a readable side-by-side record.
Third selectionOffer replacement of either existing perfume, or cancel.
Empty journalPrompt for an impression; never generate a fake personal review.

Access is part of the interface

Pair every color distinction with language. Keep the note index keyboard operable and result counts announced. Use proper row/column headings in the comparison table; preserve horizontal scrolling only within its labeled region. Avoid small, low-contrast editorial labels.

These are design provisions, not a conformance certification. Real-device, assistive-technology and user testing remain necessary.

04 / VISUAL DIRECTION

An archive
with atmosphere.

A fragrance reference library with the atmosphere of a carefully typeset perfume catalogue: photographic still lifes meet index numbers, fine rules and useful taxonomy.

Italiana + DM Sans

Italiana for large editorial display; DM Sans for controls, lists and detailed records. Titles 48–64 px at desktop, 36–42 px mobile; interface text 16 px and metadata 14 px. Avoid thin display type at small sizes.

A consistent graphic language

Oxblood type and rules on warm paper, with citron used sparingly for wayfinding accents. Fragrance imagery is illustrative; index numbering, not decorative scientific charts, gives the system its archival character.

Component & motion rules

A database first: persistent search, family filters, an alphabetic note index, card/list results, a structured dossier and a two-perfume comparison. Each active filter can be removed independently.

Subtle 160 ms border and color changes. Comparison feedback is written and announced. No floating bottle animation or parallax competes with information retrieval.

05 / REFLECTION

A reference model
to validate.

The database demonstrates an information model and interface behavior. Its usefulness at catalogue scale and the vocabulary used by real fragrance communities need further investigation.

The next validation questions

  • Test whether beginners understand a note versus a fragrance family.
  • Ask users to recover from a zero-result combination without clearing their entire search.
  • Evaluate whether comparing profiles helps someone choose what to sample without suggesting predicted performance.

No conversion, adoption, revenue or usability improvement is claimed for this concept.
